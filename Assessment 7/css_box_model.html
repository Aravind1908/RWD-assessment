The CSS Box Model

Understanding content, padding, border, and margin — with a diagram and content-box vs. border-box.

CSS · Layout · Box Model

1Introduction

Every element on a web page is rendered as a rectangular box. This box is called the CSS Box Model. Understanding it is essential for controlling spacing, sizing, and layout — because almost every layout tweak involves the box model.

From the inside out, every element's box is made of four layers:

  • Content — the actual content (text, image, etc.). It's the innermost part.
  • Padding — the space inside the border, between the content and the border.
  • Border — the line that outlines the element, separating padding from margin.
  • Margin — the space outside the border, between this element and its neighbours.

You can visualize it as a frame around a photo: the photo is the content, the picture frame's backing is the padding, the frame itself is the border, and the wall space around the frame is the margin.

2Syntax and its Explanation

The four parts are controlled by separate properties (each can also be set in a shorthand):

/* Content — sized by width & height */
width: 200px;
height: 100px;

/* Padding — inside the border */
padding: 20px;              // all sides
padding-top/right/bottom/left;   // or individually

/* Border — the outline */
border: 2px solid #333;

/* Margin — outside the border */
margin: 10px;               // all sides
margin: 10px 20px;        // top/bottom, right/left

Shorthand orders (TLBR)

padding: 10px 20px 30px 40px;  // top right bottom left
Key rule: Padding and margin look similar but are different. Padding pushes content away from the border (it's inside the box, so it adds to the box's background area). Margin pushes the whole box away from neighbours (outside, so it's transparent and sits beyond the border).

Content → Padding → Border → Margin (outermost)

3Features & Uses

1. Content — the size of the material

The actual content. Its size is set by width and height (or by default, by the content itself).

.hero { width: 400px; height: 200px; }

2. Padding — breathing room inside

Adds space between the content and the border. It does contribute to the element's total size and background area.

.card { background: #e7effc; padding: 20px; }

3. Border — the visible outline

The boundary of the box. It can be a solid line, dashed, dotted, or even a specific width/color. Like padding, it adds to the box's total width.

.btn { border: 2px solid #2563eb; border-radius: 6px; }

4. Margin — space between elements

Space outside the border that pushes the box away from its neighbours. Margins can be collapsed (top & bottom margins between adjacent elements combine into the larger one).

.box { margin: 20px auto; }  // vertical 20px, horizontal auto (centers)

5. content-box vs. border-box — what does width mean?

This is one of the most confusing — and important — differences. The box-sizing property decides whether width and height include padding and border or not.

/* content-box (default): width = content only. Padding & border are ADDED on top. */
box-sizing: content-box;

/* border-box: width INCLUDES padding and border. Total stays what you set. */
box-sizing: border-box;
Did you know? Almost every modern CSS reset sets * { box-sizing: border-box; }. This makes sizing much easier to reason about, because a width: 200px element stays 200px wide even when you add padding and a border.

4Example Programs with Explanation

Example 1 — Building and measuring a segment of the box model

This example creates a box with content, padding, a border, and a margin, and explains how each contributes to the total width.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <style>
    .box {
      /* Content */
      width: 200px;
      height: 100px;
      /* Padding inside the border */
      padding: 20px;
      /* Border */
      border: 10px solid #1d4ed8;
      /* Margin outside */
      margin: 30px;
      background: #e7effc;
    }
  </style>
</head>
<body>
  <div class="box">Box content</div>
</body>
</html>
Explanation of Example 1: With box-sizing: content-box (the default), the total width is calculated as: 
content (200px) + padding (20px+20px) + border (10px+10px) = 260px
  • Width of content: 200px (as set).
  • Padding: 20px on each side, added to the width.
  • Border: 10px on each side, also added.
  • Total box width: 200 + 40 (padding) + 20 (border) = 260px.
  • The margin of 30px is outside the box and doesn't change its width — it only adds a gap to the neighbours.

Example 2 — content-box vs. border-box side by side

Two identical-looking boxes (same width, padding, and border) end up different total sizes. The left uses content-box (default), and the right uses border-box. Open it in a browser to see the difference in total width.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <style>
    .box {
      width: 200px;
      padding: 20px;
      border: 10px solid #1d4ed8;
      background: #e7effc;
      display: inline-block;   // so boxes sit side by side
    }
    .cb { box-sizing: content-box; }   // default (bigger total)
    .bb { box-sizing: border-box; }    // width includes padding+border
    .label { font-weight: bold; }
  </style>
</head>
<body>
  <p>content-box: width 200 does not include padding+border → ~260px wide.</p>
  <div class="box cb">Content-box</div>
  <br>
  <p>border-box: width 200 does include padding+border → stays 200px wide.</p>
  <div class="box bb">Border-box</div>
</body>
</html>
Explanation of Example 2:
  • content-box — the width: 200px refers only to the content. Padding and border are added, so this box is really 260px wide.
  • border-box — the width: 200px refers to the entire box including content + padding + border. The final box stays exactly 200px.
  • This is why border-box is preferred in modern CSS: a "200px" box stays 200px no matter how much padding/border you add.
How to try it
Copy either example into a file named index.html and open it in a browser. In Example 2, use DevTools (F12 → Elements) to hover the boxes and read their measured width — the content-box is wider because padding and border are added on; the border-box stays 200px.

5Advantages

  • Predictable sizing: Understanding the box model lets you control exact element dimensions.
  • Clear spacing control: Padding for inside-space, margin for outside-space, and border for the outline.
  • Easier layout math: With border-box, you can avoid annoying off-by-padding errors.
  • Reusable components: Consistent box-model usage makes buttons, cards, and forms look uniform.
  • Better responsive design: Knowing how the box grows helps you build layouts that adapt to screen width.
  • Debugging made easy: DevTools shows the box model visually, so you can see content/padding/border/margin at a glance.

6Conclusion

The CSS Box Model is the foundation of all layout. Every element is a box made of four layers — content, padding, border, and margin — stacking from the inside out. The box-sizing property decides whether width/height measure the content (content-box) or the whole box (border-box).

In summary: content holds the material, padding adds space inside the border, border outlines the element, and margin creates space outside. Use border-box for predictable sizing, and inspect any element in DevTools to see its box model clearly. As the saying goes: "Master the box model, and you master CSS layout."
