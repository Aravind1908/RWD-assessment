Tailwind CSS: Color & Typography Utilities

How text-/bg-/border- colors work on the 50→950 scale, and how the type utilities — text-lg, font-bold, leading-, tracking- — build a full typographic hierarchy.

CSS Framework · Tailwind · Core Utilities

1Introduction

Spacing and sizing decide where things sit; color and typography decide how they read. These two utility families give every Tailwind page its face — and both work the same way: pick from a fixed scale instead of inventing values.

  • Colors come in palettes of 11 steps (50 → 950). You never type a hex code in markup — you choose a step: text-blue-600, bg-gray-100, border-blue-300.
  • Type comes in fixed scales for size (text-xs … text-9xl), weight (font-normal … font-black), line-height (leading-none … leading-loose) and letter-spacing (tracking-tighter … tracking-widest).

The payoff is consistency: two people styling the same card pick text-gray-900 for the heading and text-gray-600 for the body — the same choices everyone else makes — so projects look coherent without a style guide.

2Syntax and its Explanation

The color scale: 50 → 950

Every named color (blue, red, emerald, amber, …) has 11 steps — 50 is the lightest tint, 500 the "base" brand color, 950 nearly black:

StepTypical job
50lightest tint — section/page backgrounds
100tinted badges, pill backgrounds
200soft accents, dividers on tinted surfaces
300borders on light/tinted surfaces
400placeholder text, disabled states
500the brand base color
600primary buttons, links, accent text
700hover/pressed states, strong accent text on tints
800headings on tinted/dark surfaces
900main headings, dark text
950near-black text, dark headers & footers

Color utility syntax — property + color + step

<p class="text-blue-600">   /* text COLOR blue-600 */</p>
<div class="bg-gray-100">   /* background COLOR gray-100 */</div>
<div class="border border-blue-300"> /* border WIDTH + border COLOR */</div>

<!-- transparency: slash + percentage -->
<div class="bg-blue-500/50">   /* blue-500 at 50% opacity */</div>
<p class="text-white/70">    /* white at 70% — soft text on photos */</p>

Border utilities have three axes: width (border = 1px, border-2, border-4, border-0), side (border-t, border-b, border-l, border-r), and color (border-blue-300). Combine freely: border-2 border-b-0 border-gray-300.

Grays come in five flavors — gray, slate (cool), zinc, neutral, stone (warm) — all with the same 50→950 steps. Pick one for a project and stick to it; mixing slate and stone on one page is a classic consistency slip.

Numeric forms exist too (leading-6 = 1.5rem, tracking-[0.2em] arbitrary value). Two more helpers: font-sans/font-serif/font-mono switch families, and text-left/text-center/text-right set alignment.

Key rule: use steps, not hex codes — and pair steps by contrast: light background steps (50–100) with dark text steps (700–900) of the same hue (bg-blue-100 + text-blue-700). That pairing is readable, accessible, and instantly "on-brand".

Did you know? Every Tailwind color step is defined as an OKLCH color in v4 (perceptually uniform — steps look evenly spaced to human eyes, unlike raw HSL). And you can extend the scale with your own brand colors: in v4 that's one line in CSS — @theme { --color-brand: #2563eb; } — after which bg-brand, text-brand etc. just work.

Explanation of Example 1:
  • The swatch row renders six steps of blue (50, 100, 300, 500, 700, 950). Swap blue for emerald, amber, or rose — every family has the same 11 steps.
  • The card at the bottom is the "standard UI vocabulary" in practice: white card, gray-200 border, gray-900 heading, gray-600 body, blue-100/blue-700 badge, blue-600 button with a 700 hover.
  • Notice the badge pairs a light step background with a dark step text of the same hue — the contrast pairing rule.
How to run
Save as index.html and open in a browser with internet. Experiment: change the page's bg-gray-50 to bg-slate-50 (a different gray family), try bg-blue-500/50 on the card (transparency), and swap the button for bg-blue-700 hover:bg-blue-800 to feel the "one step darker on hover" convention.

Example 2 — Typography specimen

A page that documents its own typography — every line shows the exact classes that produce it: the size hierarchy, weights, line-heights, letter-spacing, and font families.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Tailwind Typography Specimen</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-white p-8 text-gray-900">
<div class="max-w-2xl mx-auto">

  <!-- eyebrow + display headline -->
  <p class="text-xs font-semibold tracking-widest uppercase text-blue-600">
    text-xs · tracking-widest · uppercase
  </p>
  <h1 class="mt-3 text-4xl font-bold tracking-tight text-gray-900">
    The quick brown fox jumps over the lazy dog
  </h1>

  <!-- body copy: the everyday recipe -->
  <p class="mt-4 text-base leading-relaxed text-gray-600">
    Body text usually sits at <strong>text-base</strong> with
    <strong>leading-relaxed</strong> in a mid-gray like
    <strong>text-gray-600</strong>.
  </p>

  <!-- size hierarchy -->
  <h2 class="mt-10 text-2xl font-bold">text-2xl font-bold</h2>
  <p class="text-lg font-medium">text-lg font-medium</p>
  <p class="text-sm text-gray-500">text-sm text-gray-500 — captions</p>

  <!-- tracking + leading -->
  <p class="mt-8 tracking-tight">tracking-tight — headlines</p>
  <p class="tracking-widest">tracking-widest — eyebrows</p>
  <p class="leading-none">leading-none — 1, display text</p>
  <p class="leading-loose">leading-loose — 2, spacious copy</p>

  <!-- families -->
  <p class="mt-8 font-mono text-sm bg-gray-100 rounded-lg p-4 text-gray-700">
    font-mono — code and numbers
  </p>
  <p class="mt-4 font-serif text-lg">font-serif — quotes and accents</p>

</div>
</body>
</html>
Explanation of Example 2:
  • Each line is its own documentation — the visible text names the classes that produce it, so the page doubles as a reference.
  • The headline (text-4xl font-bold tracking-tight) shows the display pattern: big, bold, and slightly negative tracking to tighten large type.
  • The body block is the default recipe: text-base leading-relaxed text-gray-600 — size, rhythm, and color in three classes.
  • The size steps and one-line tracking/leading samples make each scale tangible.
  • font-mono and font-serif switch the whole family for one element — useful for code, prices, and pull quotes.
How to run
Save as index.html and open in a browser with internet. Try bumping the headline to text-5xl, switching the body to leading-snug (tighter), and changing the eyebrow to tracking-normal to see exactly what each utility controls.

5Advantages

  • No hex-code guessing: you pick from a curated, tested palette — 11 steps per color — instead of hunting for "#3B82F6-ish" values that may not match the rest of the site.
  • Consistent contrast for free: the scale is built for pairing (light tints with dark text steps of the same hue), so common combinations are readable and accessible by default.
  • Instant theming: a brand change is a word change — blue → emerald across the file — or, in v4, one @theme line that gives you a brand color usable everywhere.
  • Transparent tints without new colors: the /NN modifier (bg-blue-500/50) adds any opacity on the fly — no extra palette entries for glassy or hover overlays.
  • A complete type system in four scales: size, weight, line-height, and letter-spacing cover every typographic decision a page needs, with names (not numbers) that read like intent.
  • Recognizable hierarchy: because everyone uses the same steps, your text-4xl font-bold tracking-tight headline and text-sm text-gray-500 caption look professional even before you've designed anything.

6Conclusion

Tailwind's color utilities (text-, bg-, border-, plus ring-, divide- and the /opacity modifier) and its typography utilities (text- sizes, font- weights, leading-, tracking-) are two more applications of the same philosophy: fixed, well-chosen scales instead of free-form values. Colors come in 50→950 steps — tints for backgrounds, 500–700 for actions, 900–950 for depth — and type comes in ladders for size, weight, line-height, and spacing.

The habits that matter: pick one gray family and stick to it, pair light steps with dark steps of the same hue, and let the four type scales — not your pixel instincts — decide the hierarchy. Do that, and every page you build will look intentionally designed.
