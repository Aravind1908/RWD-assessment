Tailwind CSS: Spacing & Sizing Utilities

The core utilities that shape every layout — padding (p-), margin (m-), gap-, width/height (w-, h-) and max-w- — with the full default spacing scale explained.

CSS Framework · Tailwind · Core Utilities

1Introduction

Of all Tailwind's utility families, spacing and sizing are the workhorses — they appear in nearly every single line of a real layout. They decide how far apart things sit (padding, margin, gap) and how big things are (width, height, max-width).

The key idea: you never type pixels. Every value is a number on a scale, and that number means "how many units of 0.25rem". So p-4 is always 4 × 0.25rem = 1rem (16px) at the default 16px base font. Learn the scale once and every p-…, m-…, gap-…, w-…, h-… becomes instantly readable. 

<!-- "a button with 8px vertical / 24px horizontal padding" -->
<!-- hand-written CSS:  padding: 8px 24px;
// Tailwind: -->
<button class="py-2 px-6">Sign up</button>
// py-2  = 2 × 0.25rem = 0.5rem = 8px  (top+bottom)
// px-6  = 6 × 0.25rem = 1.5rem = 24px (left+right)

Good to know: In Tailwind v4 the spacing scale is dynamic — any number works, because it's computed as number × 0.25rem (p-13 = 3.25rem). The table above is still the vocabulary in 95% of real code.

Padding — p-

<div class="p-4">        /* all four sides: 1rem */</div>
<div class="pt-2 pr-4 pb-2 pl-6">  /* top, right, bottom, left — individually */</div>
<div class="px-6">        /* x-axis: left AND right = 1.5rem */</div>
<div class="py-3">        /* y-axis: top AND bottom = 0.75rem */</div>

Pattern: p = all sides, pt/pr/pb/pl = one side, px = both horizontal, py = both vertical. Buttons almost always use py-* px-*.

Margin — m-

Identical letter pattern: m-4 (all sides), mt-2, mb-6, mx-auto (horizontal centering — the classic one), my-8. A minus prefix makes it negative: -mt-4 pulls an element up (overlapping avatars, badges).

<div class="max-w-3xl mx-auto">  /* mx-auto = auto left+right margins → centered column */</div>
<div class="-mt-4">          /* pull up over the previous element */</div>

Gap — gap- (flex & grid only)

gap spaces the items inside a flex/grid container — and unlike margins, it never adds space before the first or after the last item:

<div class="flex gap-4">   /* 1rem between every pair of children */
  <div>1</div><div>2</div><div>3</div>
</div>

<div class="grid gap-x-8 gap-y-2"> /* horizontal vs vertical gaps, separately */</div>

Sizing — w-, h-

Width and height share the same spacing scale: w-4 = 1rem, h-16 = 4rem. On top of the scale you get fractions and keywords:

Max width — max-w- (and friends)

max-w-* has its own scale — a handful of standard "content column" widths:

max-w-full (100%) · max-w-min · max-w-max · max-w-fit · max-w-prose (65ch — ideal text measure)

min-w-*, min-h-*, max-h-* use the same scale. The most common pairing on the planet: max-w-5xl mx-auto — "cap the width, then center it".

Key rule: gap spaces things apart inside a container; margin pushes one element away from its neighbors; padding is the space inside an element. And everything lives on the same 0.25rem scale — so a gap-4 matches a px-4 perfectly.

Rule of thumb: use gap for space between siblings (no first/last-item edge cases), mt-/mb- for space around a single element, and px-/py- for inside an element. If two adjacent numbers don't match (a gap-3 next to a px-5), the layout will feel "off" — matching scale values is what makes pages look aligned.

4Example Programs with Explanation

Example 1 — Spacing scale playground

A live page where every box's padding or gap comes from the scale, so you can see 0.25rem units with your eyes. Save as index.html (needs internet for the CDN).

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Spacing Scale Playground</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-gray-50 p-8 text-gray-900">
  <h1 class="text-2xl font-bold">Spacing scale playground</h1>
  <p class="text-sm text-gray-500">1 unit = 0.25rem (4px) — watch the blue inset grow</p>

  <!-- padding ladder: p-0 → p-8 -->
  <div class="mt-8 grid grid-cols-2 sm:grid-cols-4 gap-4">
    <div class="bg-white border border-gray-200 rounded-lg p-0">
      <div class="bg-blue-500 h-24 w-full flex items-center justify-center text-white text-xs font-mono">p-0</div>
    </div>
    <div class="bg-white border border-gray-200 rounded-lg p-2">
      <div class="bg-blue-500 h-24 w-full flex items-center justify-center text-white text-xs font-mono">p-2 = 8px</div>
    </div>
    <div class="bg-white border border-gray-200 rounded-lg p-4">
      <div class="bg-blue-500 h-24 w-full flex items-center justify-center text-white text-xs font-mono">p-4 = 16px</div>
    </div>
    <div class="bg-white border border-gray-200 rounded-lg p-8">
      <div class="bg-blue-500 h-24 w-full flex items-center justify-center text-white text-xs font-mono">p-8 = 32px</div>
    </div>
  </div>

  <!-- gap ladder: same squares, bigger gap -->
  <h2 class="mt-12 text-lg font-semibold">gap- between siblings — no margins</h2>
  <div class="mt-4 flex items-center gap-4">
    <span class="text-xs font-mono text-gray-500 w-16 shrink-0">gap-4</span>
    <div class="w-12 h-12 bg-blue-600 rounded-lg"></div>
    <div class="w-12 h-12 bg-blue-500 rounded-lg"></div>
    <div class="w-12 h-12 bg-blue-400 rounded-lg"></div>
  </div>
  <div class="mt-4 flex items-center gap-8">
    <span class="text-xs font-mono text-gray-500 w-16 shrink-0">gap-8</span>
    <div class="w-12 h-12 bg-blue-600 rounded-lg"></div>
    <div class="w-12 h-12 bg-blue-500 rounded-lg"></div>
    <div class="w-12 h-12 bg-blue-400 rounded-lg"></div>
  </div>
</body>
</html>
Explanation of Example 1:
  • The grid uses gap-4, and each cell a different p-0 → p-8 — so you see the scale: each step is exactly 4px (0.25rem) more inset than the previous one.
  • The gap rows hold identical w-12 h-12 squares; only gap-4 → gap-8 changes, doubling the space between them.
  • Notice there's no mt-/mb- between the squares — gap handles all inter-item spacing cleanly.
  • The outer page uses p-8 (32px gutters), mt-8 and mt-12 for section spacing — the same vocabulary, applied at a larger scale.
How to run
Save as index.html and open in a browser with internet. Try editing gap-4 to gap-16, or a cell's p-4 to p-13 (v4's dynamic scale accepts any number).

Example 2 — A layout built only from sizing utilities

A profile-style card where every dimension — avatar, media placeholder, fraction bars, max-width bars — is a w-/h-/max-w- utility. No single pixel is typed.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Sizing Utilities Layout</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-gray-100 p-8 text-gray-900">

  <!-- page column: cap at 48rem, center -->
  <div class="max-w-3xl mx-auto">
    <div class="bg-white rounded-2xl shadow p-8">

      <!-- avatar: 4rem × 4rem circle -->
      <div class="flex items-center gap-4">
        <div class="w-16 h-16 rounded-full bg-blue-600 text-white font-bold text-xl
                    flex items-center justify-center">A</div>
        <div>
          <h1 class="text-xl font-bold">Profile layout</h1>
          <p class="text-sm text-gray-500">Only w-, h- and max-w- utilities</p>
        </div>
      </div>

      <!-- media: full width, fixed 10rem height -->
      <div class="mt-6 h-40 w-full bg-blue-100 rounded-xl flex items-center
              justify-center text-blue-500 text-sm font-mono">w-full h-40</div>

      <!-- fractions of the parent width -->
      <div class="mt-6 flex gap-4">
        <div class="w-1/4 h-16 bg-blue-600 rounded-lg flex items-center
                    justify-center text-white text-xs font-mono">w-1/4</div>
        <div class="w-1/2 h-16 bg-blue-500 rounded-lg flex items-center
                    justify-center text-white text-xs font-mono">w-1/2</div>
      </div>

      <!-- max-width scale, centered -->
      <div class="mt-8 space-y-3">
        <div class="h-10 max-w-md mx-auto bg-blue-300 rounded flex items-center
                    justify-center text-blue-800 text-xs font-mono">max-w-md = 28rem</div>
        <div class="h-10 max-w-xl mx-auto bg-blue-500 rounded flex items-center
                    justify-center text-white text-xs font-mono">max-w-xl = 36rem</div>
      </div>

    </div>
  </div>
</body>
</html>
Explanation of Example 2:
  • max-w-3xl mx-auto caps the whole page at 48rem and centers it — the standard "readable content column" pattern.
  • The avatar is w-16 h-16 (4rem × 4rem) — sizing off the same scale as spacing, so it harmonizes with the surrounding gap-4.
  • w-full h-40 = "fill the width, 160px tall" — the usual way to reserve space for an image or hero media without knowing its width.
  • Fraction utilities (w-1/4, w-1/2) size against the parent, so they're responsive for free.
  • The bottom bars show the max-w- scale: each bar takes the full width up to its cap, and mx-auto centers the leftover space.
How to run
Save as index.html and open in a browser with internet. Resize the window: the fractions and w-full adapt automatically, and the max-w-3xl column stops growing at 768px. Swap max-w-3xl for max-w-xl and watch the page column narrow.

5Advantages

  • Instantly readable values: px-6 py-2 tells you 24px/8px at a glance — a consistent, memorable vocabulary instead of ad-hoc numbers.
  • Alignment by construction: because everything shares the 0.25rem scale, padding, margins, gaps, and small widths all snap to the same rhythm — pages look aligned without effort.
  • No pixel hunting: you never ask "was that 15px or 17px?" — you pick the nearest scale step, and it's guaranteed to match the rest of the design.
  • Fewer utilities to learn: one scale powers p-, m-, gap-, w-, h-, and more — learn it once, use it everywhere.
  • Responsive sizing for free: fractions (w-1/2) and w-full adapt to any parent; max-w-* + mx-auto gives you fluid, centered columns with two classes.
  • Easy overrides: responsive prefixes make per-breakpoint spacing trivial: p-4 md:p-8, gap-4 lg:gap-8 — tighter on phones, roomier on desktops.

6Conclusion

Spacing and sizing are the skeleton of every Tailwind layout, and both run on one idea: numbers on a 0.25rem scale. p-/px-/py- put space inside an element, m- pushes elements apart (with mx-auto as the centering classic), and gap- spaces flex/grid children without edge cases. Sizing reuses the same scale for w-/h-, adds fractions and keywords, and max-w- adds a small set of standard content-column widths.

The habit to build: think in 4px steps, and keep neighboring values on the same scale step. Do that, and your layouts will feel professionally aligned long before you ever touch a design system.
