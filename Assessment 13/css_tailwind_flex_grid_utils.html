Tailwind CSS: Flexbox & Grid Utilities

Every Flexbox and Grid property mapped to its Tailwind class — flex, items-center, justify-between, grid, grid-cols-3, col-span-* — with two complete layout examples.

CSS Framework · Tailwind · Layout Utilities

1Introduction

Flexbox and Grid are CSS's two layout systems, and Tailwind gives both a 1:1 utility vocabulary: every layout property you'd write in a stylesheet has a class name, usually a shortening of the property. display: flex becomes flex, align-items: center becomes items-center, grid-template-columns: repeat(3, 1fr) becomes grid-cols-3.

The division of labor (from the CSS guides in this series) carries over directly: Flexbox for one-dimensional flow — a navbar, a row of buttons, centering one thing — and Grid for two-dimensional structure — page frames, dashboards, card mosaics with tiles that span columns. 

<!-- the two systems in their most common form -->
<div class="flex items-center justify-between">
  <!-- logo ←→ actions, perfectly centered on the cross axis -->
</div>

<div class="grid grid-cols-3 gap-4">
  <div class="col-span-2">wide tile</div>
  <div>tile</div><div>tile</div><div>tile</div>
</div>

2Syntax and its Explanation

Flexbox utilities — the property → class map

CSS propertyTailwind classNotes
display: flexflexmake the container a flex container
display: inline-flexinline-flexinline-level flex (icon + label pairs)
flex-direction: columnflex-colstack instead of row
flex-wrap: wrapflex-wraplet items flow to new lines
justify-content: … (main axis)justify-start / center / end / between / around / evenlyjustify-between = space-between
align-items: … (cross axis)items-start / center / end / stretch / baselinestretch is the default
gap: 1remgap-4 (or gap-x-6 gap-y-2)spacing between items
align-self: start (per item)self-start / self-center / self-endone item opts out
order: 1 (per item)order-1 … order-lastreorder without touching HTML
flex: 1 (per item)flex-1grow to fill remaining space
flex: none (per item)flex-nonenever shrink/grow (logos, icons)

The two workhorses: justify- positions along the main axis (row: left→right; column: top→bottom) and items- positions across it. flex items-center justify-between is the most-typed layout line in the Tailwind ecosystem — a bar with its ends pushed apart, everything optically centered.

Grid utilities — the property → class map

CSS propertyTailwind classNotes
display: gridgridmake the container a grid
grid-template-columns: repeat(3, 1fr)grid-cols-3works for 1–12 equal columns
grid-template-columns: 2fr 1frgrid-cols-[2fr_1fr]arbitrary values for custom tracks
grid-template-rows: repeat(2, 1fr)grid-rows-2explicit rows
grid-column: span 2 (per item)col-span-2tile spans 2 columns
grid-column: 1 / -1col-span-fulltile spans every column
grid-row: span 2 (per item)row-span-2tile spans 2 rows
gap: 1remgap-4 (or gap-x-*/gap-y-*)same spacing scale as flex
grid-auto-flow: densegrid-flow-densebackfill holes from spans

For the advanced auto-fit pattern from the CSS Grid guide, Tailwind uses an arbitrary value: grid-cols-[repeat(auto-fit,minmax(200px,1fr))] — columns that appear and disappear with the width, no media queries.

Key rule: Container classes (flex, grid, grid-cols-*, gap-*, justify-*, items-*) go on the parent; item classes (flex-1, col-span-*, row-span-*, self-*, order-*) go on the children. Same rules as the CSS itself — Tailwind just renamed the properties.

Rule of thumb: one row of things? flex. A layout where rows and columns matter, or where a tile must span across its neighbors? grid. And when in doubt between the two, Flexbox is the safer default — Grid's superpower is the span, so reach for it when you need one.

4Example Programs with Explanation

Example 1 — A flexbox dashboard header + stat row

A compact dashboard top: a flex top bar (items-center justify-between) and an equal-thirds stat row where each card grows with flex-1. Save as index.html (needs internet for the CDN).

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Flexbox Layout</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-gray-50 p-6 text-gray-900">
<div class="max-w-4xl mx-auto space-y-6">

  <!-- top bar: logo left, actions right -->
  <header class="flex items-center justify-between bg-white
              border border-gray-200 rounded-xl px-5 py-3">
    <span class="font-bold text-blue-600">acme.</span>
    <div class="flex items-center gap-3">
      <span class="w-9 h-9 rounded-full bg-blue-100 text-blue-700 font-semibold
                  flex items-center justify-center text-sm">A</span>
      <button class="bg-blue-600 hover:bg-blue-700 text-white text-sm
                  font-semibold px-4 py-2 rounded-lg">New</button>
    </div>
  </header>

  <!-- equal thirds: flex-1 cards, stacked on phones -->
  <div class="flex flex-col md:flex-row gap-4">
    <div class="flex-1 bg-white border border-gray-200 rounded-xl p-5">
      <p class="text-xs text-gray-400">Users</p>
      <p class="text-2xl font-bold">1,248</p>
    </div>
    <div class="flex-1 bg-white border border-gray-200 rounded-xl p-5">
      <p class="text-xs text-gray-400">Revenue</p>
      <p class="text-2xl font-bold">$9,300</p>
    </div>
    <div class="flex-1 bg-white border border-gray-200 rounded-xl p-5">
      <p class="text-xs text-gray-400">Uptime</p>
      <p class="text-2xl font-bold">99.9%</p>
    </div>
  </div>
</div>
</body>
</html>
Explanation of Example 1:
  • The top bar is flex items-center justify-between: logo and actions are pushed to opposite ends (justify-between) and vertically centered against each other (items-center) — the workhorse pattern.
  • The right-hand cluster is its own little flex row (flex items-center gap-3) — flex nests freely, the way divs nest.
  • The stat row is flex flex-col md:flex-row (stacked on phones) and each card is flex-1 — grow equally to fill the line, so the thirds stay perfect at any width. No percentages.
  • space-y-6 on the outer wrapper adds vertical rhythm between the two blocks without margins on each child.
How to run
Save as index.html and open in a browser with internet. Resize below 768px: the stat row stacks. Try changing a stat card to flex-none and watch it stop growing — the other two absorb the space.

Example 2 — A grid dashboard with spanning tiles

A 3-column grid with a col-span-2 hero tile and a col-span-full banner tile — the two span patterns that make grid a dashboard tool.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Grid Layout</title>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-gray-50 p-6 text-gray-900">
<div class="max-w-4xl mx-auto">
  <h1 class="text-2xl font-bold">Grid layout</h1>
  <p class="text-sm text-gray-500">
    grid-cols-3 with a col-span-2 tile and a full-width banner
  </p>

  <div class="mt-6 grid grid-cols-1 sm:grid-cols-3 gap-4">
    <!-- wide tile: spans 2 columns -->
    <div class="sm:col-span-2 bg-blue-600 text-white rounded-xl p-5">
      <h2 class="font-semibold">col-span-2</h2>
      <p class="text-sm text-blue-200 mt-1">Spans two columns.</p>
    </div>
    <div class="bg-white border border-gray-200 rounded-xl p-5">
      <h2 class="font-semibold">Single</h2>
      <p class="text-sm text-gray-500 mt-1">One column.</p>
    </div>
    <div class="bg-white border border-gray-200 rounded-xl p-5">
      <h2 class="font-semibold">Single</h2>
      <p class="text-sm text-gray-500 mt-1">One column.</p>
    </div>
    <div class="bg-white border border-gray-200 rounded-xl p-5">
      <h2 class="font-semibold">Single</h2>
      <p class="text-sm text-gray-500 mt-1">One column.</p>
    </div>
    <!-- full-width banner: spans every column -->
    <div class="bg-blue-100 text-blue-800 rounded-xl p-5 col-span-full">
      <h2 class="font-semibold">col-span-full</h2>
      <p class="text-sm mt-1">Spans all columns.</p>
    </div>
  </div>
</div>
</body>
</html>
Explanation of Example 2:
  • grid-cols-1 sm:grid-cols-3 is responsive for free: one column on phones, three from sm:.
  • sm:col-span-2 makes the hero tile cover two tracks on tablets+ (and prefixing it means it behaves as a single column on phones, where spans of 2 would overflow the 1-column grid).
  • col-span-full on the banner stretches it across every column, whatever the current column count — the Tailwind form of grid-column: 1 / -1.
  • Want a tall panel or a sidebar frame? The Section 2 table covers row-span-* and the grid-cols-[16rem_1fr] arbitrary-track pattern.
How to run
Save as index.html and open in a browser with internet. Resize across 640px: the mosaic collapses to one column. Try adding row-span-2 to a tile, or changing the grid to grid-cols-2.

5Advantages

  • Layout in the markup: the entire layout is readable in the class list — flex items-center justify-between needs no stylesheet to understand.
  • A short, predictable vocabulary: ~15 flex classes and ~10 grid classes cover 95% of layouts; the names mirror the CSS properties, so CSS knowledge transfers 1:1.
  • Responsive layout for free: every layout utility accepts prefixes — flex-col md:flex-row, grid-cols-1 lg:grid-cols-3 — without writing a media query.
  • Item-level control without selectors: flex-1, col-span-2, self-center, order-last target single items directly — no nth-child tricks.
  • Composes with everything: layout utilities pair with the spacing scale (gap-4), sizing (w-full), and state variants in one class list.
  • Nesting is natural: a flex row of flex columns, a grid of flex cards — the systems nest exactly as the CSS does, with no wrapper divs added for layout.

6Conclusion

Tailwind's layout utilities are a faithful, compact rename of the CSS layout systems: Flexbox via flex, flex-col, justify-* (main axis), items-* (cross axis), gap-*, and per-item flex-1/self-*/order-*; Grid via grid, grid-cols-* (equal or arbitrary tracks), gap-*, and per-item col-span-*/row-span-*. Container classes on the parent, item classes on the children — same rules as the CSS, shorter names.

The working pairings to memorize: flex items-center justify-between for bars, flex items-center justify-center for centering, flex-1 for equal splits, and grid grid-cols-3 gap-4 + spans for mosaics. Flex for a line, Grid for a plane — and in both cases, the class list is the stylesheet.
