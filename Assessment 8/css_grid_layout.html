CSS Grid Layout

grid-template-columns/rows, the fr unit, repeat(), gap, and line placement — plus Grid vs. Flexbox.

CSS · Layout · Grid

1Introduction

CSS Grid is a two-dimensional layout system. Unlike Flexbox (which handles one axis at a time), Grid lets you lay out items into rows and columns at the same time — like a table, but far more flexible. This makes it ideal for page-level layouts: a header spanning the top, a sidebar, a main content area, and a footer.

To use Grid, an element becomes a grid container with display: grid. Its direct children automatically become grid items. You then define the grid's structure using its tracks (rows and columns), and items are placed into them — either automatically or explicitly by line number.

The key ideas are:

  • grid-template-columns / grid-template-rows — define the size of each column and row.
  • fr unit — a fractional unit that shares available space in proportion to the number.
  • repeat() — a shortcut to repeat a track pattern many times.
  • gap — spacing between rows and columns.
  • Line placement — placing items into specific grid lines (e.g., grid-column: 1 / 3).

A common rule of thumb: Flexbox for one-dimensional layout (a row or a column), Grid for two-dimensional layout (rows AND columns together).

2Syntax and its Explanation

Making a grid container

.container {
  display: grid;
  grid-template-columns: 200px 1fr 1fr;
  grid-template-rows: auto 200px;
  gap: 16px;
}

The main grid properties

The fr unit and repeat()

/* 3 equal columns */
grid-template-columns: repeat(3, 1fr);

/* 1 fixed column + 2 flexible columns */
grid-template-columns: 200px 1fr 1fr;

/* columns sized as 1fr, 2fr, 1fr (middle is twice as wide) */
grid-template-columns: 1fr 2fr 1fr;
Key rule: The fr unit divides the free space among the tracks proportionally. repeat(4, 1fr) is equal to writing 1fr 1fr 1fr 1fr — ideal for responsive columns that always fill the container.

3Features & Uses

1. grid-template-columns — define columns

Sets the width of each column. You can mix fixed sizes and flexible fr units.

.grid { display: grid; grid-template-columns: 200px 1fr; }

2. grid-template-rows — define rows

Sets the height of each row. Useful for fixed-height header/footer areas.

.layout { display: grid; grid-template-rows: 60px 1fr 80px; }

3. fr unit — share available space

A flexible fraction. 1fr 2fr 1fr splits the leftover width so the middle column is twice as wide as the outer ones.

4. repeat() — repeat a pattern

Creates many identical tracks in a compact way. Perfect for equal-width column layouts.

grid-template-columns: repeat(4, 1fr);  // 4 equal columns

5. gap — spacing between cells

Adds spacing between all rows and columns. You can use row-gap and column-gap separately.

.grid { display: grid; gap: 16px; }

6. Line placement — position items by grid line

Grid lines are numbered (starting at 1 before the first track). You can place an item between two lines using grid-column / grid-row, or use the shorthand grid-area.

.header { grid-column: 1 / 3; }  // spans from line 1 to line 3
.sidebar { grid-row: 1 / 3; }    // spans rows 1 to 3
Did you know? You can also update the grid to a well-known 12-column layout with just one line: grid-template-columns: repeat(12, 1fr) — then place sections across it, e.g. grid-column: span 6.

4Example Programs with Explanation

Example 1 — A 3-column layout with repeat(), fr, and gap

This example creates a responsive 3-column grid. It uses repeat(3, 1fr) for equal columns and gap to space them. On a narrow screen the columns naturally stay equal width and can wrap.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <style>
    /* The grid container — 3 equal columns with gap */
    .grid {
      display: grid;
      grid-template-columns: repeat(3, 1fr);
      gap: 16px;
      padding: 20px;
    }

    .grid > div {
      background: #f1e9fd; padding: 20px;
      border-radius: 8px; text-align: center;
    }

    /* The middle column is wider (2fr) — a nice emphasis */
    .grid > div:nth-child(2) { background: #7c3aed; color: white; }
  </style>
</head>
<body>
  <div class="grid">
    <div>Col 1</div>
    <div>Col 2</div>
    <div>Col 3</div>
    <div>Col 4</div>
    <div>Col 5</div>
    <div>Col 6</div>
  </div>
</body>
</html>
Explanation of Example 1:
  • display: grid makes the container a grid.
  • grid-template-columns: repeat(3, 1fr) creates 3 equal columns.
  • Six items are placed automatically into those columns, forming 2 rows.
  • gap: 16px adds space between cells.
  • Because the columns use fr, they always fill the container's width evenly.

Example 2 — A page layout with line placement

This is a full page layout using Grid line placement. A header spans the top, a sidebar runs down the left, the main content fills the middle, and a footer spans the bottom — all arranged with grid-column / grid-row.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <style>
    /* The page grid: 2 columns, 3 rows */
    .layout {
      display: grid;
      grid-template-columns: 200px 1fr;  // sidebar + main
      grid-template-rows: 60px 1fr 80px; // header + content + footer
      gap: 12px;
      min-height: 80vh;
    }

    /* Header spans BOTH columns (line 1 to 3) */
    header {
      grid-column: 1 / 3;
      background: #7c3aed; color: white; padding: 16px;
    }

    /* Sidebar spans the middle only (row 2) */
    aside { background: #f1e9fd; padding: 16px; }

    /* Main content fills the rest of the middle */
    main  { background: #fff; padding: 16px; }

    /* Footer spans both columns on the bottom row */
    footer {
      grid-column: 1 / 3;
      background: #5b21b6; color: white; padding: 16px;
    }
  </style>
</head>
<body>
  <div class="layout">
    <header>Header</header>
    <aside>Sidebar</aside>
    <main>Main Content</main>
    <footer>Footer</footer>
  </div>
</body>
</html>
Explanation of Example 2:
  • The grid has 2 columns (200px sidebar + flexible main) and 3 rows (header, content, footer).
  • header uses grid-column: 1 / 3 to span across both columns.
  • aside automatically sits in column 1; main in column 2 (both on the middle row).
  • footer uses grid-column: 1 / 3 to span the full width on the bottom row.
  • This creates a classic header/sidebar/main/footer layout with very little CSS.
How to try it
Copy either example into a file named index.html and open it in a browser. In Example 2, resize to see how the grid holds its structure. Try changing grid-template-columns to 1fr 3fr to make the sidebar narrower, or add grid-row: 1 / 3 to the sidebar to make it span the full height.

5Advantages

  • Two-dimensional layout: Control rows and columns together for real page structures.
  • Responsive by design: The fr unit and repeat() make columns adapt to container size.
  • Accurate placement: Line placement lets you position items precisely into the grid.
  • Powerful page layouts: Perfect for headers, sidebars, footers, galleries, and card grids.
  • Less markup: No wrappers or floats; just define the grid and place items.
  • Clean & maintainable: Grid makes layout intent clear and easy to reason about.

6Conclusion

CSS Grid is a two-dimensional layout system that handles rows and columns together. Use grid-template-columns/rows to shape the tracks, the fr unit to share space flexibly, repeat() to create many equal tracks, gap for spacing, and line placement to position items precisely.

In summary: Flexbox is best for one dimension (a row or a column), while Grid excels at two dimensions (rows and columns together). For a full-page structure, Grid is the natural choice; for aligning items along a single line, Flexbox is ideal. As the saying goes: "Grid for the page, Flexbox for the parts."
