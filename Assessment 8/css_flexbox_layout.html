CSS Flexbox Layout

Container and item properties — flex-direction, justify-content, align-items, gap, flex-wrap, grow, shrink, basis, order — with a navbar/card example.

CSS · Layout · Flexbox

1Introduction

Flexbox (Flexible Box) is a one-dimensional CSS layout system. "One-dimensional" means it lays out items along a single axis at a time — either a horizontal row or a vertical column. This is perfect for arranging a set of items in a line: navigation bars, rows of cards, toolbars, or centering content.

To use Flexbox, you make an element a flex container by giving it display: flex. Its direct children automatically become flex items. Then you control the layout using two groups of properties:

  • Container properties — set on the parent flex container: flex-direction, justify-content, align-items, gap, flex-wrap.
  • Item properties — set on the individual flex items: flex-grow, flex-shrink, flex-basis, order.

Flexbox is brilliant at distribution and alignment along one axis, which is why it's the go-to for horizontal navbars, button rows, and centering. (The newer CSS Grid handles two-dimensional layouts — we'll compare them in the next guide.)

2Syntax and its Explanation

Making a flex container

.container {
  display: flex;
  /* ... container properties ... */
}

The two axes (main & cross)

Flexbox has a main axis (the direction items flow) and a cross axis (perpendicular to it).

AxisDirectionControlled by
Main axisWhere items go (row default)flex-direction (row/column)
Cross axisPerpendicular to mainalign-items

Container properties

PropertyWhat it doesValues
flex-directionSets the main axis / direction items flow.row, row-reverse, column, column-reverse
justify-contentAligns items along the main axis; distributes space.flex-start, center, flex-end, space-between, space-around, space-evenly
align-itemsAligns items along the cross axis.stretch, flex-start, center, flex-end, baseline
gapAdds space between items (row-gap / column-gap).A length (e.g. 16px)
flex-wrapWhether items wrap onto multiple lines when they overflow.nowrap, wrap, wrap-reverse

Item properties

PropertyWhat it doesExample
flex-growHow much an item grows to fill free space.flex-grow: 1
flex-shrinkHow much an item shrinks when there's not enough space.flex-shrink: 0 (never shrink)
flex-basisThe starting size of the item before grow/shrink.flex-basis: 200px
orderReorders items visually without changing HTML.order: 2
Key rule: Container properties go on the parent (display: flex) and affect all its children. Item properties go on each child and affect only that one item. Remember: justify-content works on the main axis, align-items on the cross axis.

3Features & Uses

1. flex-direction — choose the flow direction

Sets whether items go left-to-right (row, default) or top-to-bottom (column).

.container { display: flex; flex-direction: column; }
.container { flex-direction: row; }   // default (horizontal)

2. justify-content — distribute along the main axis

Controls where items sit and how leftover space is shared. Common patterns: center, space-between, space-around.

.row { justify-content: center; }   // items grouped in center
.nav  { justify-content: space-between; }

3. align-items — align along the cross axis

Vertically aligns items when row is the main direction. center is very common for vertically centering content.

.navbar { display: flex; align-items: center; }
.container { align-items: stretch; }   // default — fills height

4. gap — space between items

An easy way to add consistent spacing between flex items (and also works with Grid).

.cards { display: flex; gap: 16px; }

5. flex-wrap — allow items to wrap

By default items squeeze onto one line. wrap lets them drop to the next line when there isn't room.

.container { flex-wrap: wrap; }

6. flex-grow / shrink / basis — sizing the items

These control how each item grows, shrinks, and what its starting size is.

.item { flex-grow: 1; }    // grows to fill extra space
.item { flex-shrink: 0; }  // never shrinks
.item { flex-basis: 200px; } // start at 200px

7. order — reorder without touching HTML

Changes the visual order of items. Lower numbers come first.

.item { order: 1; }    // appears later
.item { order: -1; }   // appears first

4Example Programs with Explanation

Example 1 — A responsive navbar

This example builds a navbar using Flexbox. It uses justify-content: space-between to push the logo to the left and the links to the right, and align-items: center to keep everything vertically aligned.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <style>
    /* The flex container */
    .navbar {
      display: flex;
      justify-content: space-between;  // logo left, links right
      align-items: center;                 // vertically centered
      background: #0f766e; color: white; padding: 16px;
    }

    /* The links group is ALSO a flex container */
    .links {
      display: flex;
      gap: 20px;                       // space between links
      align-items: center;
    }
    .links a { color: white; text-decoration: none; }
  </style>
</head>
<body>
  <nav class="navbar">
    <span class="logo">MySite</span>
    <div class="links">
      <a href="#">Home</a>
      <a href="#">About</a>
      <a href="#">Contact</a>
    </div>
  </nav>
</body>
</html>
Explanation of Example 1:
  • .navbar is the flex container with display: flex.
  • justify-content: space-between spreads the logo (left) and the links (right).
  • align-items: center vertically aligns the logo and the links group.
  • The inner .links is also a flex container, using gap to space the links evenly.

Example 2 — A row of flex-grow cards

This example lays out three cards side by side. The middle card uses flex-grow: 2 so it takes up twice the free space, while the others grow equally. This shows how flex-grow and gap control a card row.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <style>
    /* The container — a responsive card row */
    .cards {
      display: flex;
      gap: 16px;               // space between cards
      flex-wrap: wrap;         // wrap on small screens
    }

    .card {
      flex-grow: 1;              // each card grows equally
      background: #e4f6f3; padding: 20px;
      border-radius: 8px;
    }

    /* The middle card grows TWICE as much */
    .card.featured { flex-grow: 2; background: #0d9488; color: white; }
  </style>
</head>
<body>
  <div class="cards">
    <div class="card">Card 1</div>
    <div class="card featured">Featured (grow 2)</div>
    <div class="card">Card 3</div>
  </div>
</body>
</html>
Explanation of Example 2:
  • .cards uses display: flex, gap: 16px, and flex-wrap: wrap so cards wrap on narrow screens.
  • Each card has flex-grow: 1, so they share free space equally.
  • The featured card has flex-grow: 2, so it takes up twice as much of the leftover space.
  • flex-wrap ensures that on small screens, the cards stack rather than overflow.
How to try it
Copy either example into a file named index.html and open it in a browser. Resize the window to see the navbar and cards respond. Try changing flex-direction, justify-content, or flex-grow values to observe the effects.

5Advantages

  • Easy alignment & distribution: Center, space-out, or group items with a single property.
  • Responsive by nature: Items flex, wrap, and resize to fit the container width.
  • Great for navbars & rows: Perfect one-dimensional layouts like menus, toolbars, and button groups.
  • Order without HTML changes: order lets you reorder visually while keeping markup readable.
  • Simple centering: A two-line flex rule vertically and horizontally centers anything.
  • Clean, minimal markup: No need for floats or tricky margin hacks — flexbox handles it.

6Conclusion

Flexbox is the modern way to arrange items along one axis. As a container, you control the flow direction (flex-direction), distribution along the main axis (justify-content), alignment on the cross axis (align-items), spacing (gap), and wrapping (flex-wrap). As items, you control growth (flex-grow), shrinking (flex-shrink), the starting size (flex-basis), and visual order (order).

In summary: make the parent display: flex, then set container properties on the parent and item properties on the children. Flexbox shines for one-dimensional rows and columns, making navbars, card rows, and centering almost effortless. As the saying goes: "Flexbox makes the one-dimensional trivial."
